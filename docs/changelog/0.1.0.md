# rainmail v0.1.0

Date: 2026-09-24

rainmail 是一个降雨提醒工具: 定时查询天气接口, 在未来若干小时内检测到降水时, 通过邮件与桌面通知提醒你, 支持 Windows, macOS 与 Linux. 本版本为首次发布.

## Highlights

- `rainmail run` 一条命令即可常驻: 启动后立即检查一次, 之后按配置的间隔轮询, 只有检测到降水才会打扰.
- 内置五种天气接口, 其中 open-meteo 无需申请密钥就能用; 需要密钥的接口用 `${ENV}` 占位符引用环境变量, 口令不落磁盘明文.
- 同一场降水只提醒一次: 以地点, 降水类型与降水起始小时组成事件标识, 冷却时间内不重复推送.
- 邮件与桌面通知可同时开启, 也可只留其一; 免打扰时段默认只拦截桌面通知, 夜间仍能收到邮件.
- 配置文件带结构版本号, 后续版本改动配置结构时会自动迁移并备份原文件.

## Features

- CLI: `run` 常驻轮询, `check` 单次检查 (支持 `--dry-run`, `--force`, `--channel`, `--timeout`), `test email` 与 `test system` 分别验证两个通道, `config init|path|show` 管理配置, `version` 输出构建信息.
- 天气接口: open-meteo (免密钥), OpenWeatherMap, 和风天气, 心知天气, 以及用 gjson 路径映射任意 JSON 响应的 custom 接口; 各接口统一归一化为逐小时预报, OpenWeatherMap 的 3 小时累计降水会自动平摊到每小时.
- 降水判定: 小时降水量或天气码达标记作 "确定降水", 仅降水概率达标记作 "可能降水", 后者是否提醒由 `notify.notify_on_possible` 控制; 降雪默认不计入, 可用 `weather.include_snow` 打开. 概率与降水量来自不同预报产品, 偶尔会出现 "有雨量但概率很低" 的小时, 判断下不下以降水量与天气码为准.
- 降水时段: 相邻信号间隔超过 2 小时自动切成另一段, 提醒正文按段列出起止时间, 峰值与累计降水, 并标注每个小时的判定级别.
- 邮件: 支持隐式 TLS (465), STARTTLS (587) 与明文 (25), 认证优先 AUTH PLAIN, 服务器只支持 LOGIN 时自动回退; 正文同时提供纯文本与 HTML 两个版本, 中文标题按 RFC 2047 编码.
- 桌面通知: macOS 走 osascript, Linux 依次尝试 notify-send / zenity / kdialog, Windows 用 PowerShell 调用 WinRT Toast; Linux 缺少 libnotify 时该通道会记录失败并继续用邮件提醒.
- 去重与免打扰: 运行状态写入 `~/.local/state/rainmail/state.json`, 免打扰时段 `notify.quiet_hours` 支持跨零点, 可配置是否连邮件一起静默.
- 配置: `config_version` 配合独立迁移模块, 迁移前把原文件备份为 `<config>.vN.bak`; 默认读取 `~/.config/rainmail/config.toml`, 可用 `--config` 或 `RAINMAIL_CONFIG` 指定别处; `config show` 打印生效配置并对口令与密钥打码.
- 日志: 基于 `log/slog`, 覆盖接口查询, 判定结果, 通道发送与状态变化, 支持 text / json 格式与追加写入文件.
